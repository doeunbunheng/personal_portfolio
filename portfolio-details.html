Khmer Sentiment Engine

A full-stack multilingual NLP system that analyzes Khmer, English, and mixed (code-switched) customer comments with sentiment classification, business aspect analysis, emotion detection, and an AI chat assistant.

Project Overview

Built a complete machine-learning system that reads Khmer, English, and mixed (code-switched) customer comments and provides businesses with sentiment classification (positive/negative/neutral), 5 business aspect categories, 8 emotion labels, and an honest "not sure" flag when confidence is low.

Fine-tuned xlm-roberta-base achieving 86.6% accuracy on 30,000 balanced samples from 39,783 labeled Khmer comments sourced from HuggingFace datasets. Implemented a FastAPI backend with HMAC authentication, Streamlit dashboard with YouTube comment collection, correction tracking, and Docker deployment. The system includes an AI chat assistant that explains results in plain language with multi-provider support (offline/local/Gemini/GPT).

Features real-time YouTube comment analysis, admin correction dashboard for model improvement, and 233+ automated tests covering API, models, collectors, and dashboard. The engine processes text through Khmer-specific preprocessing including text cleaning, word segmentation, and language detection for accurate multilingual classification.
